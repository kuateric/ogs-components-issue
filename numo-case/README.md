# NUMO input directory

Copy the original NUMO input files into this directory before running the reproduction.

The validated case expects the project filename:

`shotcrete4_linear_closed_fixed_primary_D1e-12.prj`

Keep the NUMO model, chemistry, meshes, boundary conditions, stabilization and time stepping unchanged.

The original NUMO files are not committed to this public repository because they were supplied for the benchmark/investigation and are not being redistributed by this repository.
